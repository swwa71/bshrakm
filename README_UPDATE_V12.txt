واجهة v12 — تحديث المراسلات فقط

- نوع التصدير: تصدير داخلي / صادر خارجي.
- إخفاء الجهة الخارجية من الصادر الداخلي.
- إشعار بعدد الواردات الجديدة.
- الرد والإحالة للوارد مع مرفقات وبيان.
- عرض مسار المعاملة فقط والحائز الحالي.
- دعم أرقام الصادر الهجرية الجديدة الصادرة من الخادم.

لم يتم تعديل تسجيل الدخول أو إدارة النظام أو الملفات والمجلدات.
