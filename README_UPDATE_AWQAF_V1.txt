تحديث إدارة الأوقاف والأملاك - نسخة اختبار GitHub

التعديل محصور في الواجهة:
- إضافة خيار «إدارة الأوقاف والأملاك» في القائمة الجانبية فوق سلة المحذوفات.
- إضافة وحدة مستقلة داخل البوابة تشمل:
  لوحة العقارات، الأوقاف والأملاك، الوحدات، العقود، المستأجرين، التحصيل، الصيانة، المصروفات، المستندات، التقارير.
- بيانات الوحدة محفوظة محليًا في متصفح الاختبار عبر localStorage فقط.
- لم يتم تعديل Backend أو المراسلات أو الملفات أو المستخدمين أو الصلاحيات أو إعدادات السيرفر.
