# بوابة بشراكم — تجربة HTML

واجهة عربية بخط تجوّل (Tajawal)، تستخدم خلفية الجهة وشعارها. تعمل بملفات ثابتة دون تثبيت حزم أو خطوة بناء.

## تركيب التحديث على الموقع الحالي

1. فك ضغط حزمة التحديث.
2. ارفع الملفات الخمسة الموجودة داخلها إلى المستوى الرئيسي لمستودع `bshrakm`، واستبدل الملفات المطابقة: `index.html` و`styles.css` و`app.js` و`demo-store.js` و`README.md`.
3. أبقِ `background.png` و`favicon.svg` و`.nojekyll` الموجودة سابقًا كما هي؛ لا تتضمنها هذه الحزمة لأنها لم تتغير.
4. انتظر اكتمال نشر GitHub Pages، ثم أعد تحميل الصفحة. لا ترفع ZIP وحده ولا تضع الملفات داخل مجلد جديد.

التحديث يضيف رقم إصدار إلى روابط الملفات لتجنب استخدام نسخة قديمة من ذاكرة المتصفح. تنتقل بيانات التجربة السابقة إلى الشكل الجديد تلقائيًا في المتصفح نفسه وعلى عنوان الموقع نفسه. لا تمسح بيانات الموقع لتطبيق التحديث.

لمشاهدة مقدمة الدخول، سجّل الخروج ثم حدّث الصفحة: يظهر الشعار في المنتصف، يتوقف قليلًا، ثم يرتفع ويصغر، وتظهر خانات الدخول بعده. تستغرق المقدمة نحو ٣٫٣ ثوانٍ. يحترم الموقع إعداد تقليل الحركة في الجهاز.

## مسؤول النظام

- إنشاء حسابات وتعديل الأسماء وكلمات المرور والأدوار، ومنح دور المسؤول؛ لا يوجد حذف للحسابات.
- تفعيل الحساب أو إيقافه، وإنهاء جلساته، وفك القفل المؤقت. لا يمكن إيقاف آخر مسؤول مفعّل أو سحب دوره.
- تحديد مجلدات كل مستخدم، أو السماح بجميع المجلدات الحالية والمستقبلية.
- تحديد صلاحيات الرفع والتنزيل وإعادة التسمية والنقل والحذف والمشاركة لكل مستخدم عادي.
- إنشاء المجلدات وتعديل أسمائها، وإدارة ملفات النظام ونقلها وحذفها إلى السلة واستعادتها.
- التحكم بالمشاركة العامة، وحد حجم الملف والامتدادات المسموحة، والمساحة المخصصة لكل مستخدم.
- مشاهدة عدد المستخدمين والملفات والمساحة، وسجل العمليات الذي يوضح المستخدم والعملية والعنصر والوقت.
- تنزيل نسخة احتياطية وفحصها واستعادتها، بما يشمل الحسابات والصلاحيات ومحتوى الملفات والسلة والسجل.

## المستخدم العادي

- تسجيل الدخول وتغيير كلمة المرور، ومشاهدة ملفاته والمجلدات المسموحة له.
- اختيار مجلد قبل الرفع، والبحث باسم الملف أو المالك أو المجلد، وعرض حجم الملف وتاريخ رفعه.
- تنزيل الملفات، وتعديل ملفاته أو نقلها أو حذفها، وفق الصلاحيات التي منحها المسؤول.
- مشاركة ملف محدد أو جميع ملفاته مع مستخدم آخر، وإلغاء المشاركة. المستلم يحصل على الاطلاع والتنزيل فقط، ضمن مجلداته المسموحة وصلاحية التنزيل لديه.
- مشاهدة المساحة المستخدمة والمتبقية وتسجيل الخروج. تنتهي الجلسة بعد ١٥ دقيقة من عدم النشاط.

## قواعد التجربة

- اسم المستخدم يقبل الحروف أو الأرقام أو مزيجًا منهما دون مسافات. كلمة المرور من ٤ إلى ٢٠ خانة دون اشتراط نوع معين.
- يُقفل الحساب لمدة ١٥ دقيقة بعد خمس محاولات دخول فاشلة متتالية. يستطيع المسؤول فك القفل أو إعادة تعيين كلمة المرور.
- إيقاف الحساب وتغيير صلاحياته أو بيانات دخوله ينهي جلساته. تفحص الواجهة الجلسة كل خمس ثوانٍ أثناء فتحها، وكذلك عند العودة إليها وتنفيذ العمليات.
- الحد الأعلى للملف ١ جيجابايت (١٬٠٧٣٬٧٤١٬٨٢٤ بايت)، ويمكن للمسؤول تقليله. الامتدادات الفارغة تعني السماح بجميع الأنواع؛ تتطبق الحدود على الرفع الجديد وإعادة التسمية.
- المساحة الافتراضية لكل حساب ٢ جيجابايت ويمكن تعديلها، مع بقاء حد الملف الواحد ١ جيجابايت. خفض المساحة لا يحذف الملفات الحالية. حصة المتصفح الفعلية قد تكون أقل.
- الملفات في السلة تحتسب ضمن مساحة مالكها. الاستعادة تعيد الملف إلى مجلده الأصلي. أذونات مشاركة الملف المحدد تُزال عند حذفه؛ أذونات مشاركة جميع ملفات المالك تنطبق عليه مجددًا عند استعادته.
- المجلدات المسموحة شرط مستقل عن المشاركة. مشاركة ملف لا تمنح تلقائيًا صلاحية مجلده.
- سجل العمليات يبدأ من التحديث؛ لا يمكن إنشاء سجل لعمليات قديمة لم تكن مسجلة سابقًا.

## النسخ الاحتياطي

من «إدارة النظام» اختر «تنزيل نسخة احتياطية». تنتج التجربة ملفًا بامتداد `.bshbak` يشمل البيانات ومحتوى الملفات. احتفظ به في مكان خاص؛ النسخة غير مشفرة.

للاستعادة، اختر الملف ثم «فحص النسخة». ستظهر أعداد المستخدمين والملفات والمساحة قبل التأكيد. الاستعادة تستبدل بيانات التجربة الحالية بالكامل وتُنهي الجلسات؛ سجّل الدخول بعدها بحساب من النسخة المستعادة. نزّل نسخة من البيانات الحالية أولًا إذا أردت الاحتفاظ بها. إذا تعذّر الحفظ بسبب مساحة المتصفح، لا تعتمد المعاملة تغييرات جزئية.

## حدود نسخة HTML

هذه نسخة للعرض والتجربة، وليست بوابة مركزية لحفظ بيانات الموظفين الفعلية. الحسابات والأذونات والملفات محفوظة داخل المتصفح باستخدام IndexedDB؛ يمكن لصاحب الجهاز تعديلها. لا تُرسل الملفات إلى GitHub أو إلى خادم.

المشاركة وإنهاء الجلسات هنا محاكاة بين حسابات النسخة في المتصفح نفسه وعلى عنوان الموقع نفسه. لا تنتقل البيانات أو الصلاحيات تلقائيًا بين أجهزة الموظفين. النشر على GitHub Pages لا يغيّر ذلك؛ التشغيل المركزي الفعلي يحتاج خدمة خلفية وتخزينًا مشتركًا.

حذف بيانات الموقع أو التصفح الخاص قد يفقد البيانات. استخدم ملفات تجريبية واحتفظ بنسخ احتياطية. بعد تنزيل الملفات الأصلية تعمل التجربة دون اتصال بالإنترنت؛ الخط مضمّن في التنسيق، وترخيصه محفوظ فيه. الصورة والشعار للجهة صاحبة الهوية.
