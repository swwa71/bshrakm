# بوابة بشراكم — نسخة HTML للتجربة

واجهة عربية مستقلة بملفات HTML وCSS وJavaScript. لا تحتاج إلى Node.js أو تثبيت حزم أو تشغيل خادم.

## الفتح

1. فك ضغط الملف كاملًا.
2. افتح مجلد `employee-portal-html`.
3. افتح **index.html** في متصفح حديث مثل Chrome أو Edge.
4. استخدم أحد الحسابات التجريبية:

| الصلاحية | اسم المستخدم | كلمة المرور |
|---|---|---|
| مسؤول النظام | `admin` | `1234` |
| مستخدم عادي | `1001` | `1234` |
| مستخدم عادي | `ahmad` | `abcd` |

تُنشأ الحسابات في أول فتح. إذا عدّلت بيانات حساب فتُستخدم البيانات الجديدة في المرات التالية. الحسابات الافتراضية ظاهرة في صفحة الدخول لتسهيل التجربة.

## الوظائف التي يمكن تجربتها

- صفحة دخول بخلفية الجهة وشعارها، وتصميم يدعم الجوال والكمبيوتر.
- إنشاء المستخدمين وتعديل أسمائهم وكلمات مرورهم وصلاحياتهم دون حذف الحسابات، ومنح مستخدم صلاحية مسؤول النظام.
- كلمة المرور من 4 إلى 20 خانة، دون اشتراط حروف أو أرقام أو رموز. اسم المستخدم يقبل الحروف والأرقام والمزيج، دون مسافات.
- اختيار مجلد إلزامي قبل رفع الملف. يستطيع المسؤول إضافة مجلدات وتغيير أسمائها.
- حفظ ملفات تجريبية محليًا في المتصفح وتنزيلها وتغيير أسمائها ونقلها وحذفها.
- مشاركة الاطلاع والتنزيل مع حساب آخر، وإلغاء الإذن؛ صلاحية الاطلاع لا تمنح التعديل أو الحذف.
- إغلاق المشاركة أو فتحها لجميع الحسابات من إدارة النظام.
- انتهاء الجلسة التجريبية بعد 15 دقيقة من عدم النشاط.

لتجربة المشاركة: ادخل بحساب `1001`، وارفع ملفًا ثم امنح `ahmad` إذن الاطلاع. سجّل الخروج وادخل بحساب `ahmad` في **نفس المتصفح ونفس الملف أو الرابط** واختر «ملفات مشتركة معي».

## حدود النسخة التجريبية

**هذه نسخة للعرض والتجربة، وليست بوابة مركزية للاستخدام الفعلي.** كل الحسابات والأذونات محفوظة وتُعالج داخل المتصفح؛ يمكن لصاحب الجهاز تعديلها. لا تستخدم بيانات موظفين أو كلمات مرور أو ملفات حقيقية حساسة.

- التخزين يستخدم IndexedDB داخل المتصفح؛ لا تُرسل الملفات إلى خادم أو GitHub.
- الحسابات والملفات لا تنتقل بين الأجهزة أو المتصفحات، والمشاركة محاكاة بين الحسابات على الجهاز نفسه.
- حد الملف في الواجهة هو **1 GiB = 1,073,741,824 بايت**، لكن الحفظ الفعلي يعتمد على مساحة المتصفح وحصته المتاحة. لا تضمن نسخة HTML حفظ ملف بهذا الحجم على كل جهاز.
- حذف بيانات المتصفح أو استعمال التصفح الخاص أو تغيير موقع الملف قد يؤدي إلى فقدان البيانات التجريبية أو فتح مساحة تخزين مختلفة. احتفظ بنسخة أصلية من أي ملف تجريبي تحتاجه.
- إذا منع المتصفح تخزين الملفات المحلية فستظهر رسالة واضحة. استخدم متصفحًا يسمح بذلك، أو شغّل النسخة من رابط HTTPS مثل GitHub Pages.
- كل نافذة لها جلسة دخول تجريبية مستقلة؛ تُفحص تغييرات الصلاحيات عند تنفيذ العمليات أو العودة إلى النافذة.

## الرفع إلى GitHub

فك ملف ZIP وارفع **محتويات مجلد employee-portal-html** إلى المستودع، بحيث يكون `index.html` في المستوى الرئيسي مع الملفات الأخرى. لا ترفع ملف ZIP وحده إذا أردت عرض الصفحات.

النسخة ملفات ثابتة يمكن نشرها عبر GitHub Pages. لا تحتاج خطوة بناء. عند عرضها من GitHub Pages تظل البيانات محلية لكل زائر، ولا تصبح بوابة مشتركة بين الموظفين.

## الملفات

```text
index.html       صفحة الدخول والبوابة
styles.css       التنسيق العربي المتجاوب
app.js           تفاعلات الواجهة
demo-store.js    محاكاة الحسابات والأذونات والتخزين داخل المتصفح
background.png  الصورة الأصلية المرفقة من صاحب المشروع
favicon.svg     أيقونة البوابة
.nojekyll       ملف لخدمة الملفات الثابتة على GitHub Pages
README.md       هذا الشرح
```

احتفظ بهذه الملفات معًا، ولا تغيّر مواقعها دون تحديث الروابط. لا توجد مكتبات أو خطوط خارجية، وتعمل التجربة دون اتصال بالإنترنت بعد توفير الملفات.

الصورة والشعار ملك للجهة صاحبة الهوية ومرفقان حسب طلب صاحب المشروع.
