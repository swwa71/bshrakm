تحديث بشراكم - الواجهة v10
التاريخ: 2026-09-26

أهم التعديلات:
- إعادة تنظيم أنواع المستخدمين: إداري / معلم-معلمة / متطوع-متطوعة / مسؤول النظام.
- إضافة الإدارة والمدير المباشر إلى بيانات المستخدم.
- نظام صلاحيات مستقل وقابل للتوسع، ومسؤول النظام يحصل على جميع الصلاحيات تلقائياً.
- إجراءات المستخدمين والملفات والمجلدات داخل قائمة النقاط الثلاث.
- مسؤول النظام يستطيع إدارة جميع المستخدمين والملفات والمجلدات وتعديل بياناته الشخصية.
- تقييد رفع الملفات لقائمة سماح داخلية، مع فحص أولي لمحتوى الملف قبل الإرسال.
- رسالة الرفض للأنواع غير المدعومة: «نوع الملف غير مدعوم.»
- ربط رفع الملفات بالمسار الآمن الجديد /api/files/upload في Backend v6.
- صلاحيات مستقلة للمراسلات والوارد والصادر وإدارة الهيكل الإداري.

مهم:
- هذه الواجهة تحتاج correspondence_api.py من Backend v6 حتى يعمل رفع الملفات الجديد.
- لا تشغل install_correspondence.py إذا كانت وحدة المراسلات مركبة سابقاً؛ يكفي استبدال correspondence_api.py ثم إعادة تشغيل bshrakm-backend.
- لا تغير إعدادات Nginx أو Tailscale لهذا التحديث إلا إذا كنت تريد رفع ملفات أكبر من حد Nginx الحالي.
