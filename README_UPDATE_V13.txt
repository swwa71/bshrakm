تحديث v13 — المراسلات فقط

- نقل المراسلات الإدارية إلى أول القائمة الجانبية وتوحيد خطها مع بقية العناصر.
- ترتيب القائمة: المراسلات، رفع الملفات، الملفات، أذونات الاطلاع، سجل العمليات، سلة المحذوفات، إدارة النظام.
- إضافة «الأرشيف» كخيار ثالث داخل شاشة تصدير معاملة.
- إضافة حذف الصادر الداخلي من قائمة ⋯ للمرسل قبل أن يفتحه المستلم، مع بقاء صلاحية مسؤول النظام.
- لم يتم تعديل تسجيل الدخول أو المستخدمين والصلاحيات أو الملفات والمجلدات أو إعدادات السيرفر.
